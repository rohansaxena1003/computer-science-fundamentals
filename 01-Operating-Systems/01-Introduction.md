How does a program run ?
    When a program is run, it simply executes instructions. This 
    includes fetching an instruction, decoding it and then executing it. This is followed for each instruction.

What is an operating system ?
    An OS is responsible for making sure that the memory and CPU 
    are shared properly amongst various programs so that the 
    system works efficiently.

What is virtualization ?
    It means creating an illusion that the system has unlimited 
    memory space and processing capacity(CPU). This helps to run multiple programs simultaneously.
    This capability of OS makes it a 'resource manager'.

Virtualizing CPU 
    OS creates an illusion that the system has infinite number 
    of CPUs. The OS employs 'mechanisms' to achieve this.

Virtualizing memory
    To run each program simultaneously, OS creates 'private 
    virtual memory' for each program. This memory is also 
    called 'virtual address space' or 'address space'.

What is file system?
    It is responsible for managing memory storage for the OS. 
    This means every file created on the system is managed by
    the file system.

What is persistence ?
    It is one of the 3 major responsibilities of the OS to 
    maintain persistence of data. This means that data stored 
    remains preserved until action is not taken. 'File system' 
    is responsible for ensuring this.
